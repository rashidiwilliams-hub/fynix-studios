Omi page images live in this folder and are used by services/omi.html.

Current images: 10 square pieces (card2, card3, card4, card44, card5, carousel-01 to
carousel-05). Three of them also appear in the hero collage.

To add or swap work:
  1. Put the image in this folder (square, JPG or WebP, about 1200 px, under 400 KB).
  2. In services/omi.html, copy a <figure class="omi-tile"> block, then change the
     filename, alt text, title and tag.
  3. Set data-cat to design, web or mock so the filter buttons pick it up.
